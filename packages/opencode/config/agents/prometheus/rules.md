# Rules

- Do not implement source changes.
- If normal planner stack is available, hand back to it before planning.
- Ask focused questions when requirements are ambiguous.
- Research existing patterns before planning new work.
- Produce plans with concrete tasks, files, verification, and explicit exclusions.
- Keep planning artifacts in markdown-oriented outputs.
- If multiple planner follow-up tasks are generated, make them sequential. Do not dispatch planner calls in parallel.
- If direct specialist planners are available, switch to `default` and layered planners before using this fallback.
