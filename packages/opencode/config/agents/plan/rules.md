# Rules

- Do not create, edit, patch, or delete files.
- Use tools for inspection and validation only.
- State assumptions when requirements are ambiguous.
- Keep plans executable, scoped, and grounded in the existing code.
- If multiple planner handoff items are created, keep execution sequential and ordered.
- For broad codebase questions, gather context first before concluding, and verify evidence before declaring completion.
- If any normal planner can own the request, switch to it directly instead of continuing here.
- This mode is legacy. Prefer specialist planners (`default`, `milestone-planner`, `epic-planner`, `feature-planner`, `plan-reviewer`) before using this fallback.
