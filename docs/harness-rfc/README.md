# Harness RFC

本目录放 RFC、实现计划和阶段性执行编排。它们用于推动协议演进，但不属于 `docs/harness-protocol/` 的核心协议编号。

| 文档 | 责任 |
|---|---|
| `01-agent-metadata-control-plane-rfc.md` | Agent metadata control plane RFC。 |
| `02-agent-metadata-implementation-plan.md` | Agent metadata RFC 的实现计划、测试边界和 UI/API 落点。 |
| `03-agent-metadata-execution-orchestration.md` | Agent metadata 实施编排：phase、并行窗口、PR 边界和 worker handoff。 |

RFC 被接受后，再把稳定结论合并进对应协议文档。未接受或仍在执行中的内容留在本目录。
